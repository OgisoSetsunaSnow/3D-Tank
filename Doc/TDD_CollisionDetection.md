# 概述
在当前的坦克游戏中，虽然真实世间可以通过键盘和鼠标来与游戏世界进行交互。但是游戏世界之间的物体还不能进行交互。为了**构建一个可以交互的游戏世界**，那么首先要做的就是**碰撞检测**。

# 物理世界循环
**运动学的**碰撞检测的实现大致可以分为以下几个阶段
- **BoardPhase**。使用AABB盒快速的检测玩家物体可能会与哪些物体发生碰撞，但此时判断是AABB盒和AABB盒之间的碰撞关系。还不够精细
- **NarrowPhase**。初筛阶段遍历出可能会发生碰撞的两个物体之后，这个阶段是使用更加精细的手段来判断两个物体发生碰撞的深度，方向等
- **ResolvePhase**。上层用户响应碰撞检测，修正移动

# BoardPhase
最暴力的情况下我们可以使用两个for循环O(N^2)时间复杂度来实现粗筛。但是也可以有一些方法来进行优化。主要从物体和场景两个方向进行优化
## 物体简化
对于物体本身我们可以使用AABB碰撞盒或者圆形碰撞盒来将场景中的物体进行抽象和简化。在3D Tank中我们主要使用AABB碰撞盒来抽象每个模型物体。
